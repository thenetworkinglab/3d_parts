# Retro Computer 3D Part Files

A repo of various 3D files for 3D printing various computer parts that I've had to create over the years. These aren't supposed to be perfect;
they're strictly a 'good enough' effort.  Nothing would make me happier than for someone to go off and improve these.

## Models

| File | Machine | OEM part number |
| --- | --- | --- |
| `IBM PS2 Model 70 Case Foot.stl` | IBM PS/2 Model 70 | — |
| `SPARCstation 1 Rear Foot (330-1167).stl` | Sun SPARCstation 1 (rear) | 330-1167 |
| `Sun Ultra 60 Foot (330-2145).stl` | Sun Ultra 60 | 330-2145 |

## Printing

These are pretty straightforward and don't need supports.  I may not have exactly recreated the original parts (e.g. the SPARCstation rear foot doesn't have
nicely beveled edges), but they're 'close enough' for my purposes.  I've printed these out using PLA and/or TPU and they all work great.
